TP1: Application de Conversion de Devise (Euro -> DH)

Cette application Android permet de convertir un montant saisi en Euros vers le Dirham Marocain (DH) avec la gestion d'un historique des conversions via une ListView.

Technologies utilisees:
- Langage: Kotlin (.kt)
- Interface: XML (activity_main.xml)
- Composant cle: ListView avec un ArrayAdapter pour l'historique

Fichiers principaux inclus:
1. MainActivity.kt : Contient la logique de calcul de change et la gestion dynamique de la liste.
2. activity_main.xml : Definit l'interface graphique (champ de saisie, bouton de calcul, et affichage de l'historique).
